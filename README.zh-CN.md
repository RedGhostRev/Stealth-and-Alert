# 潜行与警戒

[English](README.md)

## 简介

《**潜行与警戒**》（_**Stealth and Alert**_）是一款为 Minecraft 带来类似其他游戏中的潜行与警报系统的模组。
该项目的目标是创造一种极具策略性的潜行体验，玩家必须利用阴影、视线以及环境因素来规避敌人。

## 已实现机制

- **基于视线的侦测**：真实的视锥体系统，包含水平视野（FOV）与垂直仰角判定，确保生物只能看到其视野范围内的目标。
- **环绕式 HUD 指示器**：动态的《刺客信条》风格 UI，实时追踪敌人的位置和对玩家的警戒值。
- **多阶段侦测 AI**：生物会根据其感知能力在“闲逛 (Idle)”、“怀疑 (Suspicious)”、“搜寻 (Searching)”和“战斗 (Fighting)”状态之间切换。
- **LKP (最后已知位置)**：生物会调查它们最后看到玩家的地点，而不是拥有“上帝视角”般的透视能力。
- **多人游戏同步**：在多人环境下完全同步的潜行数据，包括主目标竞争机制。
- **世界内警示表示**：直接显示在游戏世界中敌人头顶的视觉标记，用于呈现其实时的警戒状态。
- **统一可见度系统**：一个受环境因素（如光照水平）和玩家姿态（下蹲/奔跑）影响的复杂感知模型。有配套HUD。
- **环境潜行**：隐藏在特定方块中，如高草丛。
- **听觉检测**：生物会对声音做出反应，例如脚步声、方块破碎声或附近的箭矢撞击声。有配套 HUD。

## 计划中的功能

- **刺杀系统**：针对未察觉敌人的特殊处决与致命打击。
- **尸体机制**：敌人发现同伴的尸体时会进入警惕或搜寻状态。
